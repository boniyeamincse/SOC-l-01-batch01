## Quick Add Note

If you want to add a new class note quickly:

1. Create a new file in `classes/` (example: `class-03.md`).
2. Add the class title, topics, key points, and examples.
3. Add a new row in the Classes table above.
4. Add YouTube link if available, otherwise keep _Coming soon_.

## Report Note Problems

If you find mistakes in any note, please open a GitHub Issue with:

1. File name
2. Section name
3. What is wrong
4. Suggested correction

Example issue title: `Class 02: typo in SIEM section`
